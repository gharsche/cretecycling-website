## What data we collect

### For booking enquiries (rental, tours, workshops)

When you send an enquiry using the booking form, we collect the following data:

| Field | Purpose |
|---|---|
| Name | Assigning the booking |
| Email | Confirmation and communication |
| Model / tour / workshop | Processing the enquiry |
| Date / duration / persons | Availability check |
| Note (hotel, special requests) | Providing the service |
| IP address | Technical processing (log) |

The data is used exclusively to process your booking enquiry and is not passed on to third parties, unless there is a legal obligation to do so.

### Hosting (GitHub Pages)

This website is hosted via GitHub Pages (GitHub Inc., USA). When the page is accessed, GitHub may process IP addresses and other technical data in server logs. For details see the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies).

---

## Retention period

**Enquiries without a booking:** Data from booking enquiries that do not lead to a contract is stored for 6 months after the last point of contact and then deleted.

**Contract and invoice data:** For bookings that are completed, contract and invoice data is stored for 5 years (tax record-retention obligation under Greek tax law). Once the retention period expires, the data is deleted.

**Server logs (GitHub Pages):** Technical log data is processed by GitHub within the framework of its terms of use; see the [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies).

## Your rights

You have the following rights:

- **Access:** You may request information at any time about the data stored about you.
- **Rectification:** If data is incorrect, you may request that it be corrected.
- **Erasure:** You may request the deletion of your data, insofar as no statutory retention periods oppose it.
- **Objection:** You may object to the processing of your data.
- **Data portability:** You may request that your data be issued in a machine-readable format.

To exercise any of these rights, simply contact us by email at the address given above.
