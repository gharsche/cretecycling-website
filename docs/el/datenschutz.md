## Ποια δεδομένα συλλέγουμε

### Για αιτήματα κράτησης (ενοικίαση, περιηγήσεις, εργαστήρια)

Όταν στέλνετε αίτημα μέσω της φόρμας κράτησης, συλλέγουμε τα ακόλουθα δεδομένα:

| Πεδίο | Σκοπός |
|---|---|
| Ονοματεπώνυμο | Ταυτοποίηση της κράτησης |
| E-mail | Επιβεβαίωση και επικοινωνία |
| Μοντέλο / περιήγηση / εργαστήριο | Επεξεργασία του αιτήματος |
| Ημερομηνία / διάρκεια / άτομα | Έλεγχος διαθεσιμότητας |
| Σχόλιο (ξενοδοχείο, ειδικά αιτήματα) | Παροχή της υπηρεσίας |
| Διεύθυνση IP | Τεχνική επεξεργασία (καταγραφές) |

Τα δεδομένα χρησιμοποιούνται αποκλειστικά για την επεξεργασία του αιτήματός σας και δεν διαβιβάζονται σε τρίτους, εκτός εάν υπάρχει νομική υποχρέωση.

### Φιλοξενία (GitHub Pages)

Ο ιστοχώρος αυτός φιλοξενείται μέσω GitHub Pages (GitHub Inc., ΗΠΑ). Κατά την επίσκεψη στη σελίδα, η GitHub ενδέχεται να επεξεργάζεται διευθύνσεις IP και άλλα τεχνικά δεδομένα στις καταγραφές διακομιστή (server logs). Η διαβίβαση δεδομένων στις ΗΠΑ βασίζεται στην απόφαση επάρκειας της Ευρωπαϊκής Επιτροπής για το πλαίσιο EU-US Data Privacy Framework (άρθρο 45 ΓΚΠΔ)· η GitHub Inc. είναι πιστοποιημένη στο εν λόγω πλαίσιο. Λεπτομέρειες: [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies).

### Σχόλια στο Ιστολόγιο (Giscus)

Για τη λειτουργία σχολιασμού στις σελίδες του ιστολογίου χρησιμοποιούμε το **Giscus**, υπηρεσία της GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, ΗΠΑ. Το Giscus αποθηκεύει τα σχόλια ως δημόσιες Συζητήσεις GitHub στο repository μας και **δεν φορτώνει δεδομένα αυτόματα**:

- Η περιοχή σχολίων είναι αρχικά κρυμμένη. Μόλις κάνεις κλικ στο «Φόρτωση σχολίων», ο browser σου συνδέεται με το github.com. Μεταφέρονται τότε τεχνικά αναγκαία δεδομένα, ιδίως η διεύθυνση IP σου και πληροφορίες για τη σελίδα που επισκέπτεσαι· η GitHub μπορεί να τοποθετήσει τα δικά της cookies.
- **Νομική βάση** είναι η ρητή συναίνεσή σου κατόπιν του Άρθρου 6(1)(α) ΓΚΠΔ. Μπορείς να την ανακαλέσεις ανά πάσα στιγμή για το μέλλον, αν φύγεις από τη σελίδα χωρίς κλικ στο «Φόρτωση σχολίων»· ήδη φορτωμένο περιεχόμενο διαγράφεται με επαναφόρτωση της σελίδας.
- Αν σχολιάσεις ο ίδιος/η ίδια, το εμφανές όνομά σου στο GitHub και το σχόλιό σου γίνονται δημόσια ορατά σε όλο τον κόσμο. Υπεύθυνη για το περιεχόμενο και την αποθήκευση της συζήτησης είναι η GitHub.
- **Διαγραφή:** Μπορείς να διαγράψεις το σχόλιό σου απευθείας στο GitHub ή να μας ζητήσεις στο info@cretecycling.eu να το αφαιρέσουμε από τη συζήτηση.
- Λεπτομέρειες στη Δήλωση Απορρήτου της GitHub: <https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement>.

## Χρόνος τήρησης των δεδομένων

**Αιτήματα χωρίς κράτηση:** Τα δεδομένα αιτημάτων κράτησης που δεν οδηγούν σε σύναψη σύμβασης τηρούνται για 6 μήνες μετά την τελευταία επικοινωνία και στη συνέχεια διαγράφονται.

**Δεδομένα σύμβασης και τιμολογίων:** Για κρατήσεις που υλοποιούνται, τα δεδομένα σύμβασης και τιμολόγησης τηρούνται επί 5 έτη (φορολογική υποχρέωση τήρησης στοιχείων βάσει του ελληνικού φορολογικού δικαίου). Μετά τη λήξη της υποχρέωσης τήρησης, τα δεδομένα διαγράφονται.

**Καταγραφές διακομιστή (GitHub Pages):** Τα τεχνικά δεδομένα καταγραφής επεξεργάζονται από τη GitHub στο πλαίσιο των όρων χρήσης της. Λεπτομέρειες: [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies).

## Τα δικαιώματά σας

Έχετε τα ακόλουθα δικαιώματα:

- **Πρόσβαση:** Μπορείτε να ζητήσετε ανά πάσα στιγμή πρόσβαση στα τηρούμενα δεδομένα σας.
- **Ορθοποίηση:** Εφόσον τα δεδομένα είναι ανακριβή, μπορείτε να ζητήσετε τη διόρθωσή τους.
- **Διαγραφή:** Μπορείτε να ζητήσετε τη διαγραφή των δεδομένων σας, εφόσον δεν αντιτίθενται νομικές προθεσμίες τήρησης.
- **Αντίρρηση:** Μπορείτε να αντιταχθείτε στην επεξεργασία των δεδομένων σας.
- **Φορητότητα δεδομένων:** Μπορείτε να ζητήσετε τα δεδομένα σας σε δομημένη, αυτοματοσυναγώγιμη και ευανάγνωστη μορφή.
- **Καταγγελία σε εποπτική αρχή:** Με την επιφύλαξη τυχόν άλλων διοικητικών ή δικαστικών προσφυγών, έχετε το δικαίωμα να υποβάλετε καταγγελία σε εποπτική αρχή, ιδίως στο κράτος μέλος στο οποίο έχετε τη συνήθη διαμονή σας ή τον τόπο εργασίας σας ή τον τόπο της εικαζόμενης παράβασης (άρθρο 77 ΓΚΠΔ). Η αρμόδια αρχή για την CreteCycling είναι η Αρχή Προστασίας Δεδομένων Προσωπικού Χαρακτήρα (ΑΠΔΠΧ), Λ. Κηφισίας 1-3, Τ.Κ. 115 23 Αθήνα, τηλ. +30 210 6475600, e-mail contact@dpa.gr, δικτυακός τόπος www.dpa.gr.

Για την άσκηση των δικαιωμάτων σας, επικοινωνήστε με e-mail στη διεύθυνση που αναφέρεται παραπάνω.
