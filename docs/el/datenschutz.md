## Ποια δεδομένα συλλέγουμε

### Για αιτήματα κράτησης (ενοικίαση, περιηγήσεις, εργαστήρια)

Όταν στέλνετε αίτημα μέσω της φόρμας κράτησης, συλλέγουμε τα ακόλουθα δεδομένα:

| Πεδίο | Σκοπός |
|---|---|
| Ονοματεπώνυμο | Ταυτοποίηση της κράτησης |
| E-mail | Επιβεβαίωση και επικοινωνία |
| Μοντέλο / περιήγηση / εργαστήριο | Επεξεργασία του αιτήματος |
| Ημερομηνία / διάρκεια / άτομα | Έλεγχος διαθεσιμότητας |
| Σχόλιο (ξενοδοχείο, ειδικά αιτήματα) | Παροχή της υπηρεσίας |
| Διεύθυνση IP | Τεχνική επεξεργασία (καταγραφές) |

Τα δεδομένα χρησιμοποιούνται αποκλειστικά για την επεξεργασία του αιτήματός σας και δεν διαβιβάζονται σε τρίτους, εκτός εάν υπάρχει νομική υποχρέωση.

### Φιλοξενία (GitHub Pages)

Ο ιστοχώρος αυτός φιλοξενείται μέσω GitHub Pages (GitHub Inc., ΗΠΑ). Κατά την επίσκεψη στη σελίδα, η GitHub ενδέχεται να επεξεργάζεται διευθύνσεις IP και άλλα τεχνικά δεδομένα στις καταγραφές διακομιστή (server logs). Λεπτομέρειες: [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies).

## Χρόνος τήρησης των δεδομένων

**Αιτήματα χωρίς κράτηση:** Τα δεδομένα αιτημάτων κράτησης που δεν οδηγούν σε σύναψη σύμβασης τηρούνται για 6 μήνες μετά την τελευταία επικοινωνία και στη συνέχεια διαγράφονται.

**Δεδομένα σύμβασης και τιμολογίων:** Για κρατήσεις που υλοποιούνται, τα δεδομένα σύμβασης και τιμολόγησης τηρούνται επί 5 έτη (φορολογική υποχρέωση τήρησης στοιχείων βάσει του ελληνικού φορολογικού δικαίου). Μετά τη λήξη της υποχρέωσης τήρησης, τα δεδομένα διαγράφονται.

**Καταγραφές διακομιστή (GitHub Pages):** Τα τεχνικά δεδομένα καταγραφής επεξεργάζονται από τη GitHub στο πλαίσιο των όρων χρήσης της. Λεπτομέρειες: [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies).

## Τα δικαιώματά σας

Έχετε τα ακόλουθα δικαιώματα:

- **Πρόσβαση:** Μπορείτε να ζητήσετε ανά πάσα στιγμή πρόσβαση στα τηρούμενα δεδομένα σας.
- **Ορθοποίηση:** Εφόσον τα δεδομένα είναι ανακριβή, μπορείτε να ζητήσετε τη διόρθωσή τους.
- **Διαγραφή:** Μπορείτε να ζητήσετε τη διαγραφή των δεδομένων σας, εφόσον δεν αντιτίθενται νομικές προθεσμίες τήρησης.
- **Αντίρρηση:** Μπορείτε να αντιταχθείτε στην επεξεργασία των δεδομένων σας.
- **Φορητότητα δεδομένων:** Μπορείτε να ζητήσετε τα δεδομένα σας σε δομημένη, αυτοματοσυναγώγιμη και ευανάγνωστη μορφή.

Για την άσκηση των δικαιωμάτων σας, επικοινωνήστε με e-mail στη διεύθυνση που αναφέρεται παραπάνω.
