## Welche Daten wir erheben

### Bei Buchungsanfragen (Verleih, Touren, Workshops)

Wenn du über das Buchungsformular eine Anfrage sendest, erheben wir folgende Daten:

| Feld | Zweck |
|---|---|
| Name | Zuordnung der Buchung |
| E-Mail | Bestätigung und Kommunikation |
| Modell / Tour / Workshop | Bearbeitung der Anfrage |
| Datum / Dauer / Personen | Verfügbarkeitsprüfung |
| Hinweis (Hotel, Sonderwünsche) | Service-Erbringung |
| IP-Adresse | Technische Verarbeitung (Log) |

Die Daten werden ausschließlich zur Bearbeitung deiner Buchungsanfrage verwendet und nicht an Dritte weitergegeben, soweit keine gesetzliche Verpflichtung besteht.

### Hosting (GitHub Pages)

Diese Website wird über GitHub Pages (GitHub Inc., USA) gehostet. Beim Aufruf der Seite kann GitHub IP-Adressen und weitere technische Daten in Server-Logs verarbeiten. Die Übertragung von Daten in die USA beruht auf dem Angemessenheitsbeschluss der EU-Kommission zum EU-US Data Privacy Framework (Art. 45 DSGVO); GitHub, Inc. ist nach diesem Rahmenwerk zertifiziert. Einzelheiten siehe [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies).

## Rechtsgrundlage

Die Verarbeitung deiner Daten für die Buchungsanfrage und die Durchführung des Vertrags beruht auf Art. 6 Abs. 1 lit. b DSGVO. Technische Zugriffsdaten, die für den Betrieb und die Sicherheit der Website erforderlich sind, verarbeiten wir auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO.

## Speicherdauer

**Anfragen ohne Buchung:** Daten von Buchungsanfragen, die nicht zu einem Vertragsabschluss führen, werden 6 Monate nach der letzten Kontaktaufnahme gespeichert und anschließend gelöscht.

**Vertrags- und Rechnungsdaten:** Bei zustande gekommenen Buchungen werden Vertrags- und Rechnungsdaten 5 Jahre gespeichert (steuerliche Aufbewahrungspflicht nach griechischem Steuerrecht). Nach Ablauf der Aufbewahrungspflicht werden die Daten gelöscht.

**Server-Logs (GitHub Pages):** Technische Logdaten werden von GitHub im Rahmen der jeweiligen Nutzungsbedingungen verarbeitet; siehe [GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies).
